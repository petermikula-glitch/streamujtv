Promítárna pro Windows 0.1.5: klidnější rozbalovací nabídka nahoře. Otevře se, až se myš nad heslem na chvíli zastaví (pouhé přejetí přes lištu nic neotevře), a zavře se až chvíli po odjetí myši. Podnabídka se nepřepne, když myš jen šikmo přejíždí přes jiné položky do otevřené podnabídky. Rozbalují se jen kategorie (např. Objevuj → Filmy → Podle žánru → Akční), jednotlivé filmy už ne; sekce jen s filmy (Oblíbené) se nerozbaluje a klepnutím na heslo se otevře. Zip stačí rozbalit přes starou verzi, složka data zůstane.
